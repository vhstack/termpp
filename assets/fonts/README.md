# Cascadia Code NF

Nerd-Font-Variante von Microsofts Cascadia Code, unverändert übernommen aus
dem offiziellen Release. Beide Dateien sind Variable Fonts und decken alle
Schnitte von ExtraLight bis Bold ab.

Die Schriftdateien stehen unter der **SIL Open Font License 1.1** und sind von
der MIT-Lizenz dieses Repositories ausgenommen. Copyright-Hinweis und
Lizenztext liegen in `LICENSE-CascadiaCode.txt`, die Änderungshistorie des
Fonts in `FONTLOG-CascadiaCode.txt`. „Cascadia Code" ist ein Reserved Font
Name und eine Marke von Microsoft; die Dateien dürfen nur unverändert unter
diesem Namen weitergegeben werden.
